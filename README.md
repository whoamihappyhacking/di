# di

[项目主页](https://whoamihappyhacking.github.io/di/)

`di` 是一个可断开、可重新进入的终端会话工具，专门照顾 Codex、Claude Code 这类 Agent CLI 的使用体验。它用 Go 自己管理 PTY 和 Unix socket，不依赖 `dtach`。

- **attach 时零干预**：程序输出原样直达你的终端，不做二次渲染。光标、滚屏、鼠标选择、颜色、宽字符和快捷键都与直接运行完全一致，没有额外延迟。
- **重新进入时还原现场**：会话在后台用终端模拟器跟踪画面，attach 时一次性同步恢复历史滚屏、当前画面、光标和各种终端模式（备用屏、kitty 键盘协议、括号粘贴等），然后切回直通。
- **知道每个 Agent 在干什么**：运行中、待处理（响铃 / 发通知）、有更新（安静下来且有你没看过的输出）、空闲、已退出，一眼可见。

## 依赖

`di` 使用 `fzf` 选择已有会话；请先确保 `fzf` 已安装并在 `PATH` 中。

启动新会话和列出会话不依赖 `fzf`：

```sh
d <command> [args...]
d --list
```

## 安装

```sh
git clone git@github.com:whoamihappyhacking/di.git
cd di
go build -o di .
./di install
```

安装后：

```text
~/.local/bin/d
~/.local/bin/di -> ~/.local/bin/d
```

确保 `~/.local/bin` 在 `PATH` 里。升级后，已经在运行的旧版本会话可以照常列出、预览、attach 和结束。

## 用法

启动一个会话：

```sh
d codex --yolo
```

命令名支持 `$SHELL` 启动配置中的 **bash** 和 **zsh** 别名，后续参数会按原样传给命令：

```sh
d app          # alias app='app -f /etc/app.conf' → 实际执行 app -f /etc/app.conf
d app -x       # → app -f /etc/app.conf -x
```

attach 期间的按键：

| 按键      | 作用                                  |
| --------- | ------------------------------------- |
| `Ctrl-]`  | 断开 attach，后端命令继续运行         |
| `Ctrl-\`  | 打开会话切换器，切到另一个会话        |

断开时会恢复终端的各种模式，会话最后一屏会留在终端滚屏里，往上翻就能看到。

选择已有会话：

```sh
di           # 打开选择器
di codex     # 预先过滤；只有一个匹配时直接进入
```

选择器的每一行显示状态、目录、命令、摘要（窗口标题、通知或最后一句有内容的输出）和距最近一次输出的时间；下方是带颜色的画面预览。需要你处理的会话排在最前面。

| 按键      | 作用                            |
| --------- | ------------------------------- |
| `Enter`   | 进入选中的会话                  |
| `Ctrl-\`  | 移到下一个会话                  |
| `Ctrl-X`  | 结束选中的会话（运行中的会确认）|
| `Ctrl-R`  | 刷新状态                        |
| `Esc`     | 退出；从切换器打开时回到当前会话|

在会话里再运行 `d <command>` 或 `di`，外层终端会直接切到目标会话，不会出现会话套会话、快捷键被外层抢走的情况。

## 会话状态

| 状态      | 含义                                                     |
| --------- | -------------------------------------------------------- |
| ● 运行中  | 最近几秒有输出（Agent 的计时器、spinner 都算）           |
| ◆ 待处理  | 断开期间响铃或发出桌面通知，通常是等你确认或回复         |
| ◆ 有更新  | 已经安静下来，并且有你还没看过的输出，通常是一轮任务做完了 |
| ○ 空闲    | 自你上次看过之后没有新动静                               |
| ✕ 已退出  | 命令已经结束；进入一次可以看到最后的画面和退出码         |

程序如果通过 OSC 7501 主动上报状态（`state=working|blocked|idle`），以它为准。

命令在没人 attach 时结束，会话会保留最后的画面（最长 3 天），直到你进入看一眼或用 `Ctrl-X` / `d --kill` 清掉。

## 其他命令

```sh
d --list                 # 列出会话和状态，最后一列是会话名
d --attach <name>        # 按名字进入；名字可以是唯一前缀或子串
d --detach <name>        # 让所有 attach 到该会话的终端断开
d --kill <name>          # 结束会话；对已退出的会话则是清掉它
```

临时修改快捷键：

```sh
D_DETACH='^B' di
D_SWITCH='^G' di
```

## 构建

Linux/macOS 都支持。

```sh
go build -o di .
GOOS=darwin GOARCH=arm64 go build -o di-darwin-arm64 .
GOOS=darwin GOARCH=amd64 go build -o di-darwin-amd64 .
go test ./...            # 包含一个驱动真实二进制的端到端测试；加 -short 跳过
```

## 说明

`di` 解决的是“终端断开后重新进入”的问题，不是 checkpoint 工具；它不会保存进程内存、文件系统快照或网络连接状态。

attach 时输出是原样直通的，所以鼠标行为与直接运行一致：程序没有开启鼠标上报时，滚轮和选择由终端自己处理；程序开启了鼠标上报，滚轮事件会交给程序。

重新进入一个有历史输出的会话时，终端原有的滚屏会被替换成该会话的历史，避免重复；新会话不会清掉你之前的终端输出。

多个终端同时 attach 同一个会话时，会话尺寸跟随最近一次 attach 或调整窗口大小的终端。

每次启动新会话都会重新读取 shell 别名，修改被 `source` 的文件或插件后，下次启动即可生效。读取速度取决于 shell 启动配置；别名探测最多等待约 5 秒。别名会交给对应的 shell 执行，支持环境变量赋值、引号、嵌套别名和管道，额外参数中的空格或 `$()` 等内容不会被重新解释。仅在当前终端临时定义的别名需要先写入 shell 启动配置。
