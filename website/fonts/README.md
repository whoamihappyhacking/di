# Website fonts

The website serves its only web font locally, without third-party font requests.

- `terminal-mono.woff`: JetBrainsMono Nerd Font Mono Regular, used for commands and the terminal mock-up.

Source: https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/JetBrainsMono

The license notice is preserved in `OFL-JetBrainsMono.txt`.
The subset contains printable ASCII and a few box-drawing characters; other characters fall back to local monospace fonts. Text uses the system's sans-serif fonts.
