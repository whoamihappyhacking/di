# Website fonts

The website serves its fonts locally, without third-party font requests.

- `wenkai-regular.woff`: LXGW WenKai Regular, used for text.
- `wenkai-medium.woff`: LXGW WenKai Medium, used for headings and emphasis.
- `terminal-mono.woff`: JetBrainsMono Nerd Font Mono Regular, used for terminal commands.

Sources: https://github.com/lxgw/LxgwWenKai and https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/JetBrainsMono

License notices are preserved in `OFL-WenKai.txt` and `OFL-JetBrainsMono.txt`.
The subsets contain the current page's characters and printable ASCII. New text with other characters falls back to locally available fonts.
