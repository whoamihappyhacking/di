01 — PHILOSOPHY

你的工作，不该绑在
一个终端窗口上。

Agent 在思考，测试在运行，服务在等待请求。
di 在后台维持会话，让你可以断开，再从另一个终端回来。

d_
START

照常启动，多一层从容。

在命令前加一个 d，就得到一个可断开的会话。相同目录、相同命令重复运行，也会创建独立会话。

❯d <command> [args...]
^]
DETACH

离开现场，不中断工作。

Ctrl-] 断开当前客户端，后端命令继续运行。也可以从另一个终端断开指定会话的客户端。

❯d --detach <name>
di
REATTACH

看一眼，再接回去。

输入 di，用 fzf 选择会话。目录、命令与最新终端画面一起呈现，选对那个你想继续的现场。

❯di选择 → 预览 → Enter

03 — GET STARTED

下一次长任务，
带上 di。

支持 Linux 和 macOS。
准备好 Go 与 fzf，构建后即可安装。

✓ Go 1.25 或更高版本✓ fzf：用于选择已有会话✓ ~/.local/bin 已加入 PATH
github.com/whoamihappyhacking/di ↗
BUILD / INSTALL
git clone https://github.com/whoamihappyhacking/di.git
cd di
go build -o di .
./di install
INSTALLED~/.local/bin/d
~/.local/bin/di → d
先安装 fzf；不安装也可以用 d 启动和列出会话。

几个命令，就够了。

KEEP IT CLOSE

关于“留住现场”di 保持的是运行中的终端会话，不是进程快照。它不会保存进程内存、文件系统或网络连接状态，也不能在机器重启或进程退出后恢复任务。
